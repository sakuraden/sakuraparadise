# SakuraParadise (VST3 для FL Studio)

Райский вокальный процессор в стиле эмбиент.

| Крутилка | Что делает в звуке | Что появляется в раю |
|---|---|---|
| CLEAN | шумодав (экспандер) + срез низа | пыль и дымка исчезают |
| SILK | деэссер (гасит шипящие) | шёлковые ленты |
| WARMTH | тёплый низ + мягкое насыщение | восход солнца |
| AIR | воздух (хайшелф 9.5 кГц) | белые голуби |
| CHOIR | хоровой ансамбль (3 голоса) | ангелочки с нимбами |
| HEAVEN | огромный реверб | врата тории светятся, лучи |
| SHIMMER | октава вверх в реверберации | звёзды поднимаются |
| WIDTH | ширина стерео | крылья шире |
| OUTPUT | громкость | - |

Сборка: через GitHub Actions (см. инструкцию в чате) или:
  cmake -B build
  cmake --build build --config Release
